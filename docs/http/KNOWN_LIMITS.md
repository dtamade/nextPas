# nextpas.core.http 已知限制

## 协议限制

### HTTP/1.1

| 限制 | 说明 | 影响 |
|------|------|------|
| 无管道化支持 | 客户端不发送管道化请求 | 性能：需等待前一个响应 |
| 无分块 trailer 完整验证 | trailer 头未完全验证 | 安全：trailer 注入风险 |
| Connection: close 检测依赖 parser pause | 响应尾部检测基于 llhttp pause | 边界：同 TCP segment 多响应 |

### HTTP/2

| 限制 | 说明 | 影响 |
|------|------|------|
| 无服务器推送 | 服务器不能主动推送资源 | 性能：需客户端请求 |
| 无优先级树 | 流优先级未实现 | 性能：所有流同等优先 |
| 无 ALPS | 应用层协议设置未实现 | 功能：无法协商扩展 |

## 客户端限制

| 限制 | 说明 | 影响 |
|------|------|------|
| 无 HTTP/2 多路复用 | 每个请求独立连接 | 性能：连接数爆炸 |
| 无请求取消 | 无法中途取消请求 | 资源：长请求占用连接 |
| 无代理支持 | 不支持 HTTP/SOCKS5 代理 | 功能：无法穿透代理 |
| 无 Happy Eyeballs | IPv4/IPv6 串行连接 | 性能：双栈网络慢 |
| 无断点续传 | 不支持 Range 请求 | 功能：大文件无法续传 |
| 无 HTTP/2 客户端 | H2 只有服务端实现 | 功能：客户端只能 H1 |

## 服务器限制

| 限制 | 说明 | 影响 |
|------|------|------|
| 无 Graceful shutdown | 无法优雅关闭 | 可靠性：进行中请求被中断 |
| 无连接限制 | 无法限制最大并发连接 | 安全：连接耗尽攻击 |
| 无速率限制 | 无内置速率限制 | 安全：需外部中间件 |
| 无请求体大小限制 | 无内置 body 大小限制 | 安全：大 body 耗尽内存 |
| 线程池模型 | 每连接一线程 | 扩展性：高并发线程数大 |

## 安全限制

| 限制 | 说明 | 影响 |
|------|------|------|
| 无 CSRF 防护 | 需外部实现 | 安全：跨站请求伪造 |
| 无压缩 | 不支持 gzip/brotli | 性能：响应体积大 |
| 无速率限制 | 需外部实现 | 安全：暴力攻击 |

## 性能限制

| 限制 | 说明 | 影响 |
|------|------|------|
| 快速路径仅 GET 200 | POST/PUT 无快速路径 | 性能：写请求全走 llhttp |
| 无零拷贝 body | 大文件缓冲到内存 | 内存：大文件 OOM |
| 无 sendfile | 不支持内核零拷贝 | 性能：大文件 CPU 复制 |
| 无 SIMD header 匹配 | 线性扫描 header | 性能：大量 header 慢 |

## 兼容性限制

| 限制 | 说明 | 影响 |
|------|------|------|
| 仅 FPC 编译器 | 不支持 Delphi | 兼容性：仅 Free Pascal |
| 仅 POSIX + Windows | 其他平台未测试 | 可移植性：需平台适配 |
| llhttp 依赖 | 需要 llhttp 共享库/静态库 | 部署：需额外依赖 |
