## 三、开发流程

### 3.1 AI 辅助开发模式

```
用户需求 → AI 分析 → 方案设计 → 用户确认 → AI 实现 → 验证 → 合入
```

### 3.2 工作纪律

1. **计划先行**: 每轮开始前输出任务清单（≤5 条）
2. **契约优先**: 先定义接口契约，再实现
3. **测试驱动**: 先写测试，再写实现
4. **最小变更**: 每次提交原子化，≤200 行
5. **复盘总结**: 每轮结束复盘，更新目标树

### 3.3 质量门禁

| 门禁 | 命令 | 通过标准 |
|------|------|----------|
| 编译器编译 | `scripts/rebuild-compiler.sh` | 成功 |
| Pass 测试 | `make test TEST_FILTER=compiler-pass` | 34/34 |
| Smoke 测试 | `make test-smoke` | 9/10 |
| 产物卫生 | `make hygiene` | 0 violations |
