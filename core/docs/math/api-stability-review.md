### 2.2 变更影响分析

**向后兼容变更** (无破坏性):
- Vec.Swizzle 属性: 新增属性，不影响现有代码
- Vec.Clamp 方法: 新增方法，不影响现有代码
- SumSquaredDeviations: 新增函数，不影响现有代码
- Batch API: 新增函数，不影响现有代码

**行为变更** (需注意):
- TotalVariance: 修复了错误的实现，从 PopnVariance 改为 ANOVA 定义
  - 旧行为: `Σ(xi - x̄)² / N`
  - 新行为: `Σ(xi - x̄)²`
  - 影响: 使用 TotalVariance 的代码可能需要调整

**优化** (行为不变):
- Fmod: 混合策略优化，行为完全兼容
