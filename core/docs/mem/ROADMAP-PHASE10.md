# Phase 10: 分配器组合与集成

## 目标
4 个分配器/工具，聚焦组合性和实际应用场景。

## P10-1: TFailAllocator — 故障注入分配器 ✅
- 可配置在第 N 次分配时失败
- 测试 OOM 处理路径
- 支持 SetFailAt 动态调整
- 适合：健壮性测试、错误注入
- 测试：7 个

## P10-2: TPrefixAllocator — 前缀元数据分配器 ✅
- 每次分配前存储大小前缀
- O(1) 查询任意指针的分配大小
- 无需额外查找表
- 适合：需要知道分配大小的场景（序列化、拷贝）
- 测试：7 个

## P10-3: TThreadSafeAllocator — 线程安全包装器 ✅
- 用 TMemMutex 包装非线程安全的分配器
- Acquire/Release 保护每次操作
- 适合：将单线程分配器安全用于多线程
- 测试：7 个

## P10-4: TBatchAllocator — 批量分配器 ✅
- 一次分配多个相同大小的块
- BatchAlloc/BatchFree 批量操作
- 支持混合批量和单次分配
- 适合：对象池预热、批量初始化
- 测试：7 个

## 结果
- 新增源文件：4 个
- 新增测试：28 个
- Phase 10 完成后：41 allocator 文件 / ~905 测试
