**日期**: 2026-07-20  
**状态**: **EXECUTED / CLOSED**（L-core + L5）  
**基线**: Era K CLOSED · Maintenance Idle · 再扫后  
**目标**: 关掉 **size 可知/可补字段** 的最后几处 mem-owner 单 slab / 已知 raw 路径；**不**碰 tui、不扫 IAllocator 实现体。

## 1. 为何这是「下一批最适合」

| 选项 | 为何不优先 |

| allocator 实现体 FreeMem | 接口转发，不是样板战役 |

| 触点少（2 必做 + 1 可选），验证门清晰 |
| 不跨模块、不 raw merge 大枝 |

## 3. 设计要点

### L1 — TLocalBlockPool

```pascal
// field
FBackingSize: SizeUInt;

// Create after LTotalSize known
FBackingSize := LTotalSize;
FBacking := FAllocator.GetMem(...) / GetMem(...);

// Destroy
if FBacking <> nil then
begin
  if FAllocator <> nil then
    FreeMemOf(FAllocator, FBacking, FBackingSize)
  else
    FreeMem(FBacking, FBackingSize);  // process GetMem 路径
end;
```

- 实现 `uses nextpas.core.mem`（若尚未）。  
- nil allocator 用过程式 `GetMem`/`FreeMem(size)`（与 J2 BlockPool 一致）。

### L2 — TFixedSlabPool 主区

```pascal
// field
FRawAllocSize: SizeUInt;

// Create
FRawAllocSize := allocation_size;
FRaw := FAllocator.GetMem(FRawAllocSize);

// Destroy（主区）
if FRaw <> nil then
  FreeMemOf(FAllocator, FRaw, FRawAllocSize);
```

- **本批不改** AlignedFallback 路径（L6）；Destroy 里 `FreeActiveAlignedFallbacks` 仍 unsized，单独标注 WAIVE/后续。

### L5（可选）— TSlabPool fallback

```pascal
// free fallback
LRawSize := LAlloc.Size + LAlloc.Alignment - 1;  // 与 AllocFallback LNeeded 一致
if LAlloc.Alignment <= 1 then LRawSize := LAlloc.Size;
FreeMemOf(FAllocator, LAlloc.RawPtr, LRawSize);
```

- 适用于：`AllocFallback` except、`ReallocMem` 旧块、`FreeMem` fallback 分支、Destroy 扫 `FFbRawPtrs`（需并行 size/align 或从 map 删除时取 size）。
