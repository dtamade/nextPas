## 根因与修复（本 lane）

### 1. `sysutils facade public surface drifted` — **期望过时，非解析截断**

轻启动时怀疑 `facade_parser.sh` 在 type alias 后截断。复现后 actual 已解析出完整 interface 表面；expected allowlist 落后于 facade 扩展。

**actual 相对旧 expected 的增量**（均已在 `nextpas.core.system.sysutils.pas` interface 中）：

- types: `TBytes`
- functions: `IntToHex`, `BytesOf`, `StringOf`, `CompareMem`, `ExpandFileName`, `GetTempDir`×2 (overload), `GetProcessID`, `ExecuteProcess`
- const: `PathDelim`

**修复**：更新 `require_sysutils_facade_surface_allowlist` expected 与真实 interface 对齐（禁止删断言）。

### 2. `system unit bypasses platform owner: … uses BaseUnix`

`GetProcessID` 直接 `uses BaseUnix`/`Windows`，违反 system 不得绕过 OS 单元的 source-contract。

**修复**：去掉 BaseUnix/Windows；`GetProcessID` 委派 FPC `System.GetProcessID`（该符号在 System 而非 SysUtils）。不复制第二套 root 类型，不引入 platform 直连。

### 3. FPC RTL file-level debt：`net.async.udp` 用 SysUtils

main 上已存在的 `nextpas.core.net.async.udp.pas uses SysUtils`，未进 `fpc_rtl_file_allowlist.txt`，source-contract 在 facade 绿后暴露。

**修复**：在 allowlist 记一条命名 debt（baseline 诚实，不迁 net 实现）。**不**在本 lane 改 net 代码。
