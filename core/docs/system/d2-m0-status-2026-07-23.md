## D3 residual honesty（2026-07-23）— process 收口 + host-free 绑定策略

### A. Process residual 诚实收口

| 证明什么 | 不证明什么 |
| --- | --- |
| 有 `process-*-runtime` typed 节点时，`_start` 含 `np_process_init` / `np_process_fini` HIR call | 全量 runtime 业务 init（unit 表 / 堆 / ExitProc） |
| LLVM：`declare void` + `call void`（单次 fini；非 `call i64`） | host-free 端到端「process 业务 init」可执行证明 |
| 无 lifecycle 节点时不发明 process call | 退出码经关闭序列保留（历史主张，非当前权威） |
| ledger / coverage 边界 | 仍 **scelHir** + **Runtime execution deferred** |

**收口结论**：process residual **作为证据边界已诚实闭合**（call-shape only）。
**不是**「process 生产完成」；**禁止**假抬 ledger / 读成 self-host。

### B. Host-free 绑定策略（不改全局默认）

| 规则 | 事实 |
| --- | --- |
| host-free 证明 **必须** | `--toolchain-binding linux-x86_64-to-linux-x86_64-llvm`（或门禁 env 等价） |
| transcript 必须 | `backend-family=llvm` + `primary-tool-profile-id=llvm-stable` + `llvm-toolchain-status=ready` |
| 拒绝 | `primary-tool-profile-id=fpc-stage0-host` 冒充 host-free |
| 默认 `nextpas build`（无 llvm binding） | `fpc-stage0-host` / host FPC — **不能**当作 host-free 证据 |
| 门禁入口 | `make test-compiler-unit-init-chain` · `test-compiler-unit-fini-body` · `test-compiler-unit-lifecycle-llvm` |
| **禁止** | 改全局默认 toolchain binding |
