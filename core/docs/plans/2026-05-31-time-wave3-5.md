# nextpas.core.time Wave 3-5 Implementation Plan

> **Goal:** 为 async/reactor 提供时间基础设施：Deadline、Timer、Ticker、Sleep、Period

## Codex 设计审查（session 019e7cf3）

### 执行顺序
- Wave 3: TDeadline + TSleep
- Wave 4: TTimer + TTicker  
- Wave 5: TPeriod + ISO 8601 P1Y2M3D

### 设计原则
- 全部 record + value semantics（与现有 TDuration/TInstant 一致）
- Polling-based（不引入 callback/线程）
- TDeadline 建立在 TInstant（单调时钟）上
- TPeriod 只做 years/months/days（不碰 clock-part）

### 新增单元
- `nextpas.core.time.deadline.pas` — TDeadline
- `nextpas.core.time.sleep.pas` — TSleep
- `nextpas.core.time.timer.pas` — TTimer
- `nextpas.core.time.ticker.pas` — TTicker
- `nextpas.core.time.period.pas` — TPeriod

### 质量门禁
- 每个类型 100% 接口测试覆盖
- heaptrc 零泄漏
- 基准对照（Go time 包）
- Codex 复盘

## Wave 3: TDeadline + TSleep

### TDeadline API
```
At(TInstant) / After(TDuration) / Infinite / Expired
IsInfinite / IsExpired(ANow) / TimeUntil(ANow) / Remaining(ANow)
ToInstant / Min(A, B)
```

### TSleep API
```
ForDuration(TDuration) / Until(TDeadline)
```
